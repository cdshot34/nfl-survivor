Set up this device

Pick a password and paste a GitHub token. The token gets encrypted with the password and stored in this browser only. Use the same password on every device — it is also what keeps picks hidden until the deadline.

How to make one
  1. Open the fine-grained token page.
  2. Repository access → Only select repositories → .
  3. Permissions → Repository permissions → Contents → Read and write.
  4. Set an expiry past February, generate, copy it.

There is no password reset. If you forget it, clear the device and set up again with a new token — nothing else is lost, since the picks live in the repo.

Device settings

The encrypted token is held in this browser only. It never goes into the repo and is only ever sent to api.github.com.

Reveal key. Picks entered before a deadline are hidden on the board. A GitHub Action unhides them once the deadline passes, and it needs this key. Add it once as a repository secret named REVEAL_KEY: new repository secret. The key comes from your password, so it only changes if the password does.
